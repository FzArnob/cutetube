Install

  1. Download CuteTube-Setup.exe with the button above.
  2. Run it and accept the Terms of Use and Privacy Policy. It installs for your user account, so no administrator rights are needed.
  3. Open CuteTube from the Start menu, sign in to the sites you use, and start saving.

If Windows SmartScreen shows “Windows protected your PC”, that's because the release is new and has few downloads so far. Check that the publisher and file come from this site, then choose More info → Run anyway. You can compare the file's SHA-256 checksum with the one on the release page.
